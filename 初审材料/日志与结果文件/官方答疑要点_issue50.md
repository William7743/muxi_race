# 官方直播答疑要点（GitLink issue 50，2026-08-20）

来源：https://www.gitlink.org.cn/metax-maca/op_optimization/issues/50

## 与本方案直接相关的官方结论

1. **【成绩作废条款】**"发榜单位会检查成功提交的代码。异步拷贝不符合题目规则，
   一经发现，对应成绩将作废。"（赛题一 Q1）
   → 本包最终代码 v432（OJ 135985）经静态扫描与人工审计，不含任何异步拷贝/
   流水线/import_source/call_extern/外部库/跨调用缓存，合规风险为零。
2. **【BSM 内建】**"相关能力已经开放"（赛题一 Q7）——BSM 内建文档面向所有赛题
   开放；但在赛题一"禁用异步"条款下，BSM 的异步用法仍不可用于本赛题提交。
3. **【计时口径】**每个测试点取**平均数**（OJ Q1）；`tb_time_ms` 为 baseline
   一次性预跑的**固定参考值**（OJ Q2）→ 选手分数波动完全来自自身用时随机器
   档位的波动，与官方计分逻辑一致。
4. **【同分排名】**同分不因提交时间罚排名（OJ Q3）。
5. **【性能方法论（官方推荐）】**先建立带宽/计算预期 → 判断 compute-bound 或
   memory-bound → 用 mcProfiler/mcTracer 定位 → 从 block size / tile size 调优
   入手 → 重点研究官方内建指令文档。本方案的实验路线（流量模型 + 分块扫描 +
   记分板重叠）与该官方建议一致。

## 对历史决策的复盘意义

- 本团队曾独立验证"MACA 无 cp.async、Pipelined ns≥2 纯负收益"（-20%+），与
  官方禁用异步的规则互为印证：合规与性能在这一点上方向一致。
- 团队在 8/28 发现的"评测机速度 1.5× 波动"现象，由官方 Q2 的固定 tb_time_ms
  机制解释：分母恒定，分子随机器档位波动 → 慢档日全榜分数系统性下移。
