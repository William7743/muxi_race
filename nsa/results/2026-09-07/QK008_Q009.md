# Register ablations rejected as global replacements

All measurements use complete run_kernel, normal fresh inputs/current partial
blocks, FP32 reference cast to FP16, four ABBA orders and ten calls per batch.
B4/L1024/H1/HQ16/S1. Every recorded comparison passes full-output correctness.

No broad benefit; do not merge. Small D32/BS32 change alone is insufficient
to establish a repeatable gain. Raw: qk008.jsonl/log.

## NSA009: only chunk Q in fragments, seed318

D128/BS16: baseline56.79us, candidate60.40us (regression).
D128/BS32: baseline80.01us, candidate76.03us (~1.05x).
The BS32 effect is smaller than the already validated CK4 improvement;
no global replacement or combination is justified. Raw: q009.jsonl/log.

Next NSA010 changes only the fixed PV output loop from T.serial(CV) to
T.unroll(CV), using the installed TileLang public loop API. Mathematical
operations/output regions are unchanged. Both full-output checks pass:
BS16 baseline56.68us vs55.55us; BS32 baseline80.60us vs79.78us (seed319).
Only1-2% difference, not yet separated from session noise. No promotion.
Raw: unroll010.jsonl/log.

NSA011 keeps all GPU math and pass settings identical to #115804 but selects
