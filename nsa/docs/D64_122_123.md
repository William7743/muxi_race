# NSA122/123: bound the single-block D64 load addresses

2026-09-09. NSA109 remains the immutable, actual OJ 86.00 baseline.
These candidates do not change attention math or cache results.

## Design and scope

For aligned sequence length L and BS=16, a causal nonnegative block ID obeys
0 <= block_id <= t//BS <= L//BS-1. Therefore block_id % (L//BS) is an identity
on every admitted block, and its entire K/V block lies within [0,L).
Guard the original ID before using the modulo expression. This exposes a
bounded address to the compiler and removes the redundant full-block/fallback
load branch. The safe-memory pass remains enabled. QK/PV, probability casts,
softmax, masks, barriers, tile sizes, prefetch and output stores are unchanged.

NSA122 clones four D64 factories: plain, K-fragment, V-prefetch and combined.
Dispatch requires S=1,D64,G16,BS16,L divisible by16 and B*L*H>=4096.
Nonaligned/small/other shapes retain the parent. The modulo is not a way to
wrap a sentinel into a valid block: the guard rejects the original sentinel L.
Negative/all-masked rows are not new supported semantics or correctness proof.

NSA123 retains only the plain-factory clone, under the same shape conditions.
The existing parent dispatch determines whether that factory is selected.
It does not dispatch on values, testcase order, warmups or evaluation phase.
Other paths remain NSA109. Among the 14 formal shapes, only case5 is intended
to change. Arbitrary valid aligned shapes using the same factory can also change.

the three unmodified prefetch/fragment routes,high-amplitude inputs and
uniform-score cancellation. All checks use the declared .01 absolute/relative
tolerance; this is not bitwise equality or proof of all possible inputs.

All14-case generated-source hashes are checked:only case5 changes. NSA122
and NSA123 case5 generated CUDA are identical. They eliminate both K/V
fallback branches and their64-bit address forms, retaining uint4 loads;
the bounded index becomes block_id &63 for this aligned length. MMA,
warp-barrier and reduction call-site counts are unchanged. This is generated
source evidence, not hardware instruction/occupancy profiling.

Files,results and generated-source hashes are bound by the verification
script. Minimal source diffs are saved alongside the raw JSONL. An initial
local report-generation attempt hit Windows GBK decoding on Chinese comments;
explicit UTF-8 fixed the report script. GPU sources/results were not changed.

NSA123 is a small-gain candidate worth optional manual OJ validation, not a
new best verified score. Applying the independent seed457 ratio only to the
