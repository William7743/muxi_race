# NSA116–118: V-only layout with synchronization control

2026-09-09, parentNSA109. No OJ submission. All candidates are standalone files.

EarlierNSA036/037 varied all Q/K/V layouts on an older kernel; here only Vs is
annotated, preserving current Q/K layouts, scalar conversions, prefetch and math.
API is the installed TileLang0.1.10 MACA `make_mma_swizzle_layout`. It maps
shared addresses only; no imported external device code or new asynchronous work.

- 118 is the control: replace the two warp-only Vs lifetime barriers in
  `nsa_d128_scheduler` with full CTA barriers, preserving default layouts.
- 116 adds Vs vecSize16 to118.
- 117 adds Vs vecSize4 to118.

Changing layout can affect warp ownership. Full CTA barriers conservatively
protect shared V read-to-output-overwrite and output-read-to-next-refill handoffs.
The already-existing other CTA barriers remain. AST audit proves all other
factories/dispatch unchanged and verifies the32x64 layout maps bijectively.
This is not proof of bank-conflict counts or all compiler behaviors.
