# NSA138–140: H2 scalar-output bounded loads

## Design

Parent is frozen NSA128, the engineering control. Actual highest OJ remains
NSA133/#141741/86.64; its extra point came on unchanged point13, not its packed-V
change. This experiment targets point13 with an actual generated-code change.

138 clones nsa_simplified_h2_scalar_output. Its parent selection requires
H=2,D64,G16,BS16,S1,workload B*L*H<=1024. The additional gate requires aligned
L%BS==0; nonaligned shapes retain the parent. The original block ID is checked
before applying a modulo expression: for0<=block_id<=t//BS, and0<=t<L, alignment
implies block_id<L//BS, so block_id%(L//BS) is an identity. This makes the complete
K/V block's bounds explicit to the compiler. Sentinel L is rejected before modulo;
it is not wrapped into a valid index.

Remove redundant full-block/fallback K/V branches in the clone. Keep QK/PV,
softmax, probability casts, scalar output conversion, thread count, shared layout,
load order, barriers and all pass configs unchanged. Safe-memory legalization
stays enabled. This does not add supported semantics for all-masked queries.

139 adds V-fragment prefetch ahead of the reductions to138;140 instead moves Q
after K. Those are independent alternatives, not cumulative changes.
The AST audit reconstructs each clone using an explicit transformation whitelist,
checks its decorator unchanged and proves every pre-existing function unchanged
except one shape-only dispatch condition. No async/pipeline/external device
implementation or cached results are introduced.
