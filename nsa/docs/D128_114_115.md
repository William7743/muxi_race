## Isolated designs

- NSA114 removes the shared-output round trip after scalar FP16 conversion in
  `nsa_d128_scheduler`. It writes the same fragment-to-output coordinates and
  retains a full CTA barrier between CV iterations to protect Vs reads/refills.
  Earlier reference-repository v299/v300 had tried direct output before scalar
  conversions and regressed. This is a revisit of that route with the current
  conversion path, not a novel or already-established improvement.
- NSA115 retains the original shared epilogue, replacing per-element probability
  division with row reciprocal and multiplication. Floating-point order changes;
  real arithmetic equivalence does not establish numerical equivalence.

Only the named factory changes; all dispatch and other factories remain identical
under AST audits. No new async, external device implementation or result cache.
Python syntax checks and audits pass. Static store bijection does not prove the
compiler's fragment layout or race freedom; target numerical tests are additional
evidence, not a universal proof.
